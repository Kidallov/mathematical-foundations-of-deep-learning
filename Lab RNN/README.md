## Сохранённые результаты

В `artifacts/assignment/` находятся `best_model.pt`, `vocabulary.json`, `config.json`, `data_stats.json`, `history.json`, `summary.json`, `learning_curve.png`.

В `artifacts/example/` находятся лучшие веса, словарь, история, сводные метрики и график примера. Словарь и веса каждого опыта образуют пару: использовать словарь одного корпуса с весами другого нельзя.

`.pt` содержит только `state_dict`. Для восстановления создайте `ElmanLanguageModel` из соответствующего ноутбука с размером сохранённого словаря, затем примените `model.load_state_dict(torch.load(path, map_location='cpu', weights_only=True))` и `model.eval()`. Это не требует повторного обучения или загрузки корпуса. Архитектура и все размеры указаны в отчёте и коде.

## Повторный запуск

Просмотр сохранённых выводов не требует обучения. Для нового запуска нужен интернет: корпус читается потоково. Исходные тексты не сохраняются в папку работы; библиотека Hugging Face может использовать свой обычный внешний кэш.

В терминале перейдите в `Lab RNN`, создайте окружение Python 3.12 и установите зависимости:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m ipykernel install --prefix .venv --name python3 --display-name 'Python 3 (Lab RNN)'
```

Выполните пример, затем самостоятельный вариант:

```bash
.venv/bin/python run_notebook.py 01_elman_rnn_language_model_example_executed.ipynb
.venv/bin/python run_notebook.py 02_elman_rnn_language_model_completed.ipynb
```

Либо откройте ноутбуки в Jupyter/редакторе, выберите ядро этого окружения и выполните все ячейки сверху вниз. Код сам выбирает устройство CPU. Файлы ноутбуков и артефакты экспериментов при новом запуске перезаписываются; сделайте копию, если нужно сохранить первоначальные результаты. Текстовые отчёты фиксируют уже выполненный запуск и автоматически не пересчитываются.

В закреплённых версиях основных пакетов используются Python 3.12 и PyTorch 2.13.0. Методичка рекомендует Python 3.13; фактическое отличие явно отражено в отчёте. Результаты могут немного различаться между платформами даже при одинаковом SEED. Самостоятельная модель использует ручной Elman-переход, а не готовый рекуррентный слой.
